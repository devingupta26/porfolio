# Devin Gupta — Portfolio Website

Personal portfolio website for Devin Gupta — Full-Stack AI Builder & Software Developer.

## 🚀 Built With
- **HTML5**: Clean, modern, accessible semantic structure.
- **Pure CSS3**: Custom modern design with cohesive nautical/slate palette, glassmorphism, floating physics animations, and responsive layout without external frameworks.
- **Typography**: Google Fonts (*Plus Jakarta Sans*, *Space Grotesk*, and *Bebas Neue*).

## 💻 Running Locally
You can serve the portfolio locally using any static web server:

```bash
# Using Python
python -m http.server 8000
```

Then visit **http://localhost:8000** in your browser.
